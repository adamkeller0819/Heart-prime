# plan.md — Concept 001: Island naming (dry run)

## Question
Name the starting island of the YTIR home plane, Echo.
Candidates on the table: Tern, Drift, Wren, Hale.

## Context
- The island holds the opening village of the hero's journey
  (Kalos Ignus Hearthgaurd's home).
- YTIR naming rules: names are load-bearing. Spelling, pronunciation,
  and reversals carry lore meaning. Check each candidate for canon
  collisions and quiet lore work (reversals, anagrams, real-world
  collisions).
- This is a dry run of the council loop itself. Keep feedback short.
  The real test is the machinery: read the plan, write your feedback
  file, follow the dropbox rules.

## What each planner should weigh
- Heart (Meta): which name holds the most warmth — the one that
  feels like home?
- Dread (Claude): which name carries the right weight — the cost
  of leaving it, what's at stake?
- Chaos (Gemini): which name ripples best — reversals, anagrams,
  unexpected readings?

## Deliverable
Each planner: one pick, one sentence of reasoning, filed as your
feedback file in the Drive concept folder.
