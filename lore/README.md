# YTIR lore — shared canon

**Authority:** Adam Keller (founder). Luma (lore archivist) maintains these files.
**Pronunciation:** "Yatir".

This directory is the council's shared lore memory. Planners (Meta/heart,
Claude/dread, Gemini/chaos) read from here; they do not edit. When Adam rules
on an open question, Luma moves it from `open-questions.md` into `canon.md`.

## Files

- `canon.md` — the ruled canon. Everything in here is decided. Treat it as
  ground truth for any concept work.
- `port-package-2026-09-27.md` — the full v1→v2 lore port record (Sep 27–28,
  2026): what was ported from `emotional-rpg-core` into the Figma Make build,
  what was quarantined as AI drift, and the 13 judgment calls that were left
  as open questions rather than silently decided.
- `changelog.md` — dated log of lore changes and their verification state.
- `open-questions.md` — everything awaiting Adam's ruling. Not canon.

## Rules

1. Canon in `canon.md` overrides all older repository, prototype, and site
   material, including anything in `emotional-rpg-core` or
   `Emotionalrpgenhanced` that contradicts it.
2. Bracketed `[NEEDS RULING]` items are questions, never defaults. Do not
   treat a recommended default as decided.
3. Mechanics are not lore. Class abilities, paths, subclasses, bestiary
   stats, and systems design belong to the mechanics lane (heart/dread/chaos
   planners) — not here.
4. Luma is the sole committer for this directory.
